
# Aula Digital — Projecte Intermodular SMX

Transformació d'una aula tradicional en una aula digital: mobiliari específic per a ordinadors, armari rack amb switch i router, rosetes RJ45 a la paret per a una xarxa d'àrea local amb intercomunicació entre l'alumnat i el professorat, eixida a internet, pissarra digital i impressora en xarxa.
